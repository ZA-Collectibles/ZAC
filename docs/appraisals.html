One useful photograph can be enough to begin.

Clear photographs, basic context and what you want to know are enough for the first conversation. If the object warrants more, we can ask for the specific evidence that will improve the answer.

Before you submit

Questions people usually ask.

Do I need to know exactly what the object is?

No. Uncertainty is normal. A broad photograph and any context you have are enough to begin.

Do I need professional photographs?

No. Clear phone photographs in good light are usually more useful than heavily edited images.

What if it needs physical inspection?

We can explain what cannot be established remotely and what examination would be useful next.
